# RTL8812EU 5.15.0.1 离线安装工程

用于在 **Ubuntu 22.04 / x86_64（amd64）** 电脑上离线编译、安装 RTL8812EU USB 无线网卡驱动。无需在目标电脑连接互联网。

## 一、快速安装

将整个压缩包复制到目标电脑，解压后打开终端：

```bash
tar -xzf rtl8812eu-offline-ubuntu22.04-amd64.tar.gz
cd rtl8812eu-offline-ubuntu22.04-amd64
./install.sh --check
sudo ./install.sh
```

安装脚本会校验工程文件、检查系统和内核、从包内安装所需依赖、编译并注册 DKMS，然后加载驱动。一般不需要重启。以后内核更新时，DKMS 会尝试为新内核重编译；对应内核头文件仍需齐全。

安装后检查：

```bash
./check.sh
nmcli device status
nmcli device wifi list
```

网卡名称通常为 `wlx` 加 MAC 地址，每台网卡可能不同。安装脚本不配置 Wi-Fi 密码，不自动连接热点。

## 二、适用范围

| 项目 | 范围 |
| --- | --- |
| 系统 | Ubuntu 22.04，amd64 / x86_64 |
| 已实机验证的内核 | `6.8.0-85-generic` |
| 包内附带的内核头文件 | `6.8.0-85-generic` 及其公共头文件 |
| 其他内核 | 须已安装匹配头文件，或按第三节提前补齐离线依赖；兼容性以实际编译和加载结果为准 |
| 不适用 | Windows、Ubuntu 20.04/24.04、ARM/aarch64、Jetson 等其他系统或平台 |
| Secure Boot | 本工程的自动安装要求关闭；已开启时停止并提示，不修改固件设置 |

驱动实际版本为 `v5.15.0.1-249-g9245f8bd9.20241218_COEX20240913-390e`，内核模块名为 `8812eu`，DKMS 项目名为 `realtek-rtl88x2eu/5.15.0.1~20230815`。DKMS 版本沿用源码中的历史名称，不代表驱动实际发布日期。

已实机验证 USB ID `0bda:a81a`。源码还含 RTL8822EU 的其他 USB ID，但本工程没有对这些型号进行实机验证。保留原源码的功能配置，未额外开启 AP/P2P。

## 三、给其他内核提前准备离线包

先在目标电脑查看：

```bash
uname -r
dpkg --print-architecture
cat /etc/os-release
```

假设目标内核是 `6.8.0-XX-generic`，在一台**能够联网的 Ubuntu 22.04 amd64 电脑**上解压工程并运行（将示例替换为实际内核）：

```bash
sudo ./tools/prepare-online.sh --kernel 6.8.0-XX-generic
```

联网准备工具需要 Python 3 和可用的 HTTPS 证书（Ubuntu 桌面系统通常已具备）。它会刷新软件源元数据，下载所需工具和指定内核头文件的完整依赖，保留已有包，并重建离线索引及校验清单。它不会安装这些软件包，也不会更换正在运行的内核。软件源必须仍然提供目标内核的精确头文件版本。

然后把**更新后的整个工程目录**复制到离线电脑，运行 `sudo ./install.sh`。不能只复制新增的某一个 `.deb`，因为索引和校验清单也发生了变化。

若目标电脑系统包更新得比本离线包更晚，可能出现版本依赖无法满足。安装脚本不会强制降级系统包；应在联网电脑重新准备依赖，或使用与目标电脑一致的系统镜像制作离线包。

## 四、工程内容

```text
install.sh                 离线安装入口
check.sh                   只读环境与驱动检查
uninstall.sh               卸载本工程安装的驱动
driver/rtl8812eu/           已验证的完整驱动源码
driver/COPYING             GPL-2 许可文本
packages/                  Ubuntu 离线依赖及本地软件源索引
tools/prepare-online.sh    联网电脑下载工具
SOURCE.json                源码来源、版本和原始压缩包校验值
SHA256SUMS                 工程校验清单
VALIDATION.md              本次验证结果与边界
logs/                      执行时产生的日志
```

源码参考：[svpcom/rtl8812eu v5.15.0.1](https://github.com/svpcom/rtl8812eu/tree/v5.15.0.1)。本工程使用设备上已验证的源码副本，原始 ZIP 的精确校验值记录在 `SOURCE.json`；未声称 ZIP 对应某个已核实的 Git 提交。

**请使用工程根目录的 `install.sh`。** `driver/rtl8812eu/dkms-install.sh` 是保留的上游原始脚本，其中有全局关闭 IPv6 的操作和不一致的 DKMS 命名；本工程安装入口不会调用它，也不修改现有网络配置。

## 五、重复安装与卸载

重复运行安装入口会检查已有源码，避免静默覆盖同名但内容不同的驱动。遇到冲突时根据提示处理，不要直接覆盖 `/usr/src`。

```bash
sudo ./uninstall.sh
```

默认移除本工程的 DKMS 注册和安装文件，已加载的驱动可继续保留到下次重启。若需要立刻卸载内存中的驱动：

```bash
sudo ./uninstall.sh --unload
```

`--unload` 会断开使用此网卡的连接，请在本地终端或其他网卡的 SSH 连接中执行。卸载不会删除通用编译工具、系统内核头文件或其他网卡配置。

## 六、故障检查

- **缺少内核头文件**：头文件必须对应完整的 `uname -r`，不能拿另一个内核版本的头文件替代。
- **USB 只显示 `12M`**：用 `lsusb -t` 检查链路速度。这次实机存在此现象，驱动仍可扫描 Wi-Fi，但速度会受 USB 链路限制，需要检查线材、转接板或接口。
- **已识别网卡但未连接**：驱动安装与 Wi-Fi 连接是两个步骤；在系统网络设置中选择热点并输入密码。
- **换到另一台电脑**：本机验证结果不能替代该电脑的 USB 硬件、射频、联网和吞吐测试。先运行 `./check.sh`，再进行实际连接测试。

高级用法：`sudo ./install.sh --kernel <完整内核版本> --no-load` 可以为指定内核准备模块而不加载，主要用于离线构建验证。普通安装无需这些参数。
